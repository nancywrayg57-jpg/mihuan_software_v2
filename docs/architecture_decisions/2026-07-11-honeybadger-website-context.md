# Honeybadger Website Context Consolidation

## 核心结论

- 项目不是 Demo，而是正式对外发布的多语言企业官网项目。
- 首期以展示型官网为主，不建设复杂后台系统。
- 官网需要支持中文、英文、俄语三种语言。
- 官网必须明确说明蜜獾公司是俄罗斯 `zennolab` 公司在中国的运营实体。

## 已确认范围

- 独立域名：`https://www.honeybadgersoft.com/`
- HTTPS：`Let's Encrypt`，自动续签
- 企业邮箱：阿里云企业邮箱
- 页面范围：首页、关于我们、产品介绍、新闻资讯、人才招聘
- 视觉方向：参考 `zennolab.com`
- LOGO：可在现有基础上重设计
- 导航要求：统一页头导航与页脚信息，页面包含面包屑导航，语言切换位于导航栏
- 页脚要求：预留 ICP 备案信息与版权信息位置，不单独展示
- 客服要求：桌面端、移动端所有页面常驻客服悬浮按钮，点击后支持微信、QQ、钉钉在线沟通咨询
- 首页模块：包含“新闻资讯”模块，下设“企业活动”“行业新闻”
- 关于我们模块：品牌介绍、品牌定位与形象展示、企业背景介绍、公司主体说明、联系我们
- 产品介绍模块：产品介绍文案与素材展示、产品能力说明
- 新闻资讯模块：企业活动、行业新闻

## 技术与架构边界

- 当前不需要后台，优先按静态站或弱后台方案实施
- 首期不建设订单、支付、库存、资金等业务系统
