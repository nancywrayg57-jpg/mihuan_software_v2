# Honeybadger Website PRD Consolidation

## 核心结论

- 当前项目的正式需求基线为 `docs/requirements_v2.md`。
- 项目定位仍为正式对外发布的多语言企业官网，而非业务交易系统。
- 首期范围以展示型官网为主，默认不包含复杂后台 CMS、会员、支付、订单等业务系统。
- 官网必须显著说明蜜獾公司是俄罗斯 `zennolab` 公司在中国的运营实体。

## 已确认范围

- 域名：`https://www.honeybadgersoft.com/`
- HTTPS：`Let's Encrypt`，支持自动续签
- 语言：中文、英文、俄语
- 页面：首页、产品介绍、新闻资讯、人才招聘、关于我们
- 公共能力：统一导航、页脚、面包屑、导航栏语言切换、全局客服悬浮按钮
- 客服渠道：微信、QQ、钉钉
- 对外邮箱：阿里云企业邮箱
- 视觉方向：参考 `zennolab.com`

## 关键待确认项

- 是否建设后台 CMS
- 三语文案提供方式与责任人
- 客服账号或二维码素材
- LOGO 重设计范围
- 联系方式、ICP 备案号与页脚最终文案

## 使用约定

- 后续若继续推进官网设计或开发，以 `docs/requirements_v2.md` 作为当前需求基线。
- 若后续另行建立正式 PRD 并替代该文件，必须先完成文件落地与相关收敛文档同步，再推进设计、开发或测试。
