# Honeybadger Website Governance Consolidation

> 状态：历史记录，仅供追溯。本文保留 2026-07-12 的治理收敛背景；当前 repo、UI、客服与部署事实以 `Agent.md`、`UI/`、`docs/生产物料清单.md`、`docs/蜜獾官网项目需求分析.md` 和 `docs/开发路线图.md` 为准。

## 核心结论

- 根目录 `Agent.md` 已建立为当前项目唯一有效的 Agent 宪法文件。
- 根目录 `Codex工程经验.md` 已建立为当前项目的执行经验沉淀文件。
- 当前需求单一事实源为 `docs/requirements_v2.md`。
- 当前工作区已有 `.git` 与 `UI/` 静态官网实现，`UI/` 可作为正式开发的前端页面参考与迁移基线；若继续静态站交付，应基于现有页面完成生产化修正、旧路由清理和上线验证。

## 关键治理决策

- 首期项目定位固定为正式对外发布的多语言企业官网，不是 Demo、CMS 项目或交易系统。
- 首期范围固定为 5 个一级页面：首页、产品介绍、新闻资讯、人才招聘、关于我们。
- 首期全站公共能力固定包含导航、页脚、面包屑、语言切换、全局客服悬浮按钮、正式域名访问与 HTTPS。
- 首期默认采用“展示站 + 结构化内容配置”策略；在未明确更新需求前，不引入复杂后台 CMS。
