# 蜜獾官网需求

## 1. 项目目标

- 建设蜜獾正式对外发布的企业官网独立站。
- 对外展示公司形象、产品能力、企业背景与招聘信息。
- 在官网中明确说明蜜獾公司是俄罗斯 `zennolab` 公司在中国的运营实体。

## 2. 项目范围

- 项目类型：企业官网独立站。
- 站点形态：前台展示型网站。

## 3. 已确认需求

### 3.1 域名与安全

- 官网使用独立域名：`https://www.honeybadgersoft.com/`
- 网站启用 `Let's Encrypt` 证书
- 证书支持自动续签

### 3.2 品牌与内容

- 官网整体风格参考 `zennolab.com`
- LOGO 可在现有 LOGO 基础上重设计
- 网站需支持中文、英文、俄语三种语言

### 3.3 页面范围

1. 首页
2. 产品介绍
3. 新闻资讯
4. 人才招聘
5. 关于我们

### 3.4 页面模块需求

#### 首页

- 首页需显著标明蜜獾公司是俄罗斯 `zennolab` 公司在中国的运营实体

#### 关于我们

- 品牌介绍模块
- 品牌定位与形象展示模块
- 企业背景介绍
- 公司主体说明
- 联系我们

#### 产品介绍

- 产品介绍文案与素材展示
- 产品能力说明

#### 新闻资讯

- 企业活动模块
- 行业新闻模块

### 3.5 站点要求

- 页面需自适应桌面端与移动端分辨率
- 页面需具备统一的页头导航与页脚信息
- 页面中需包含面包屑导航，位于页头导航下方
- 语言切换功能需放置在导航栏中
- 页脚部分需预留 ICP 备案信息位置和版权信息位置
- 网站需提供全局在线客服功能，在桌面端、移动端所有页面常驻显示客服悬浮按钮
- 访客点击客服悬浮按钮后，可选择通过微信、QQ、钉钉三种方式联系工作人员进行咨询
- 对外邮箱使用阿里云企业邮箱

## 4. 交付范围

- 官网需求文档
- 页面信息架构
- 视觉设计稿
- 前端项目代码
- 部署配置
- 三语内容清单
- 上线检查清单

## 5. 验收标准

- 官网可通过正式域名访问，且 HTTPS 正常生效
- 首页及核心页面完整上线
- 中文、英文、俄语内容均可正常切换与浏览
- 官网显著说明蜜獾与 `zennolab` 的关系
- 页面在桌面端与移动端均可正常浏览
- 导航栏包含语言切换功能，页面包含面包屑导航
- 页脚中的 ICP 备案信息位置与版权信息位置预留完成
- 在线客服悬浮按钮在桌面端、移动端所有页面常驻可见
