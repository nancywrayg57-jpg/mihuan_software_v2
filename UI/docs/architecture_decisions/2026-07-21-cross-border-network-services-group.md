# 产品页跨境网络服务整合板块

- 产品数据继续保留静态住宅 IP、机房 IP、动态 IP 三个独立条目，确保原有名称、介绍、标签与详情链接不丢失。
- 对外产品范围统一为“4 项常规产品/服务 + 跨境网络服务（含静态住宅 IP、机房 IP、动态 IP）”；三类 IP 不再拆分为顶层产品方向。
- 产品页渲染时将前三类非网络产品保持原布局，将产品数组末尾的三类 IP 服务统一包裹在 `network-services-group` 中。
- 整合板块新增“跨境网络服务”一级标题和中、英、俄三语说明；三个子产品仍使用统一的 `productCard` 渲染函数。
- 新板块复用官网蓝色波浪资源与现有卡片设计，仅增加分组层级和 PC 三列布局；窄屏沿用单列响应式规则。
- 三个子产品详情页与原有路由保持不变，本次不修改其业务内容。
- 历史阶段行为：产品导航下拉仅展示前 4 项常规产品/服务，并将三类 IP 菜单合并为一个三语“跨境网络服务”入口；该入口曾定位到产品页 `#network-services` 整合板块，已被下一条独立页入口替代。
- 新增独立 `跨境网络服务.html` 页面及 `en`、`ru` 同名入口，页面状态键为 `network-services`；导航合并入口改为直接打开该页面。
- 独立页面不复制产品业务数据，而是按 `static-ip`、`idc-ip`、`dynamic-ip` 三个键读取 `PRODUCT_DETAILS`，统一渲染规格、核心优势、适用场景与原详情入口。
