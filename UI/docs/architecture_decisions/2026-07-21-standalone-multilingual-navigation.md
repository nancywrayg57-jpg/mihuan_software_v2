- 内容与格式：直接复用原项目 `assets/app.js` 的五页三语内容和 `assets/styles.css` 的原始视觉格式，不复制或改写业务文案。
- 页面模型：沿用 `home`、`products`、`news`、`careers`、`about` 状态及原有渲染函数；仅拦截主导航链接，在当前 HTML 中更新页面状态。
