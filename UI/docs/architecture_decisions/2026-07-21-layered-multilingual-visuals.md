# 分层视觉图的多语言文字适配

- 项目内没有带文字的位图资源，SVG 仅承担无文字的背景与装饰图形。
- 首页、产品、新闻资讯、人才招聘、关于我们共用的界面示意图由 HTML/CSS 分层生成；背景、浏览器框、流程编号和进度条继续作为稳定图形层。
- `visualCard()` 根据全局 `state.lang` 选择中文、英文或俄语文字层，语言切换触发原有 `render()` 后自动同步更新。
- 图片语义说明同样按语言生成，并通过 `role="img"` 与本地化 `aria-label` 暴露给辅助技术。
- 较长俄语文本允许在固定卡片内换行，不改变官网蓝色商务视觉、图形尺寸和 PC 端布局。
